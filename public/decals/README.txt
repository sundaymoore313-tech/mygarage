Decal assets folder

Put your decal image files here.

Supported formats (recommended):
- .png (best for transparency)
- .webp
- .jpg

Recommended file naming:
- lowercase, dash-separated
- examples: stripe-red.png, sponsor-logo.webp, number-23.png

Default path pattern to use in the app:
- /decals/<file-name>

Examples:
- /decals/stripe-red.png
- /decals/sponsor-logo.webp
