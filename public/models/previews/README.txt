Static Car Preview Images

Place static preview images here for the car selector.

Filename rule:
- Match the model file base name exactly.
- Example model: 2019_chevrolet_corvette_c8_stingray.glb
- Example preview: 2019_chevrolet_corvette_c8_stingray.png

Supported preview formats:
- .webp (recommended)
- .png
- .jpg
- .jpeg
- .avif
- .svg

Lookup order used by selector:
1) /models/previews/<model-base>.<ext>
2) /models/<model-base>.<ext>
3) generated fallback thumbnail

Tip:
- Use 1:1 aspect (e.g. 768x768 or 1024x1024) for best card composition.
