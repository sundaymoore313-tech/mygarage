Font assets folder

Put custom font files here for text decals.

Supported formats:
- .ttf
- .otf
- .woff
- .woff2

Recommended file naming:
- FamilyName-Weight.ext
- examples: Orbitron-Regular.ttf, Rajdhani-Bold.ttf

Default path pattern to use in the app:
- /fonts/<file-name>

Examples:
- /fonts/Orbitron-Regular.ttf
- /fonts/Rajdhani-Bold.ttf
